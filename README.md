# Coral Cutter

海底を動き回り、海藻やサンゴを刈って基地で売り、潜水艦を強化するトップビューのブラウザゲームです。「刈る → 満タン → 売却 → 強化」は数分で回ります。深海に着くまでにはカッターと深度の両方が要り、ゲートだけを買うプレイでもおおよそ45分以上かかります。放置収入や酸素ゲージはありません。プレイヤー自身がカッターで刈ります。

## あそびかた

1. 潜水艦を動かして海藻に触れ、カッターで切断します。
2. 刈った分はタンクに積まれ、潜水艦の上に荷物が積み上がります。タンクには上限があります。
3. いっぱいになったら中央の基地（光る円）に戻りましょう。円に入ると自動で売却され、コインが舞い、所持金が増えます。
4. 基地にいるあいだ、強化パネルから次を購入できます。
   - **カッター** … 威力、射程、切断できる硬さ（16段階。費用は約1.4倍ずつ）
   - **深度** … 進める海域。カッターと両方ないと先の輪に入れません（6段階）
   - **タンク** … 積載量（10段階）
   - **プロペラ** … 移動速度（8段階）
   - **売却価格** … 売値の倍率（8段階）
   - **デコイ** … 深海や沈没船で奪われる量を減らす（4段階）
5. 基地から離れるほど海域は硬く、単価も上がります。深度が足りない輪には押し戻され、今のカッターで切れないものは火花とともに弾かれます。必要なレベルまで強化して戻ると、それまで弾かれていたものがまとめて割れます。深い海域ほど群れが密で、分あたりの収入も上がります。浅瀬は最初の刈り場です。地図の半径は400で、以前の約3倍の広さです。
6. 基地のパネルは「強化 / 設備 / 拠点」です。拠点レベルをお金で上げると、設備が解放されます。
   - **納品建設** … 今いる場所に前線基地（納品ポイント）を建てます。円に入るとタンクを売れます。数の上限は拠点レベルで増えます。強化の購入は本拠地だけです
   - **吸い込み** … 潜水艦の周囲も刈ります
   - **ドローン** … プレイ中だけ、タンクの一部を最寄りの売却地点へ運んで売ります。タブを隠しているあいだは止まったままです
   - **加工所** … 海藻以外の売値が上がります
   - **ソナー** … でかい獲物、真珠、掘り場をミニマップに出します
   - **ワープ** … 基地から自分の前線基地へ飛びます。最大だと前線から基地へも戻れます

   数字の調整は `src/game/economy.js` にまとめてあります。放置収入やオフライン収入はありません。

### 海域

| 海域 | 範囲（基地からの距離） | 入場 | ほかにあるもの |
| --- | --- | --- | --- |
| 浅瀬 | 16〜84 | 最初から | ヒトデ、砂の貝、大貝、魚 |
| 昆布の森 | 84〜175 | カッターLv4・深度Lv2 | 海ぶどう、沈んだ箱 |
| サンゴ礁 | 175〜275 | カッターLv7・深度Lv3 | イソギンチャク、扇サンゴ、石像 |
| 沈没船 | 東のポケット。中心 (220, -144)、半径 34 | カッターLv9・深度Lv4 | 板、スクラップ、錨 |
| 深海 | 275〜340 | カッターLv11・深度Lv5 | チューブワーム、結晶、石板 |
| 深海の奥 | 340〜400 | カッターLv13・深度Lv6 | 奥の大貝と遺物 |

カッターの硬さは Lv4 で昆布、Lv7 でサンゴ、Lv9 で貝殻、Lv11 で深海サンゴです。Lv12以降は深海に入ったあとの威力で、最大は Lv16 です。拾い物・魚・牽引・掘りの単価も `src/game/economy.js` にまとめてあります。

短いあいだに連続で刈るとコンボが付き、そのぶん売値が少し増えます。

各海域に「でかい獲物」が1つあります。浅瀬のかたまり、昆布の幹、巨大サンゴ、沈没船の宝箱、深海の光柱です。数秒切り続けると割れ、ふつうの海藻よりずっと高い荷物がまとめて入ります。カッターが足りないあいだは小さな錠が出ます。割ったあとしばらくするとまた生えてきます。いつもそこを周るだけではタンクは埋まらないので、周りの海藻やサンゴも刈ってください。

刈るのが収入の中心です。同じ移動操作のまま、次のものも拾えます。追加のボタンはありません。

- **拾う** … 浅瀬のヒトデと砂の貝、昆布の海ぶどう、深海の結晶。上を通るとタンクに吸い込みます。単価は周りの海藻より低めです。
- **魚** … 近づくと逃げます。カッターの輪の中まで追い込むと網に入り、よく売れます。
- **大貝** … ゆっくり開閉します。開いているあいだに切ると真珠。閉じていると弾かれます。硬い海域の貝は、その海域と同じカッターが必要です。
- **牽引** … 箱・錨・石像・石板はタンクに入りません。触れるとケーブルで繋がり、基地の円まで引くと大きく売れます。引いているあいだは遅くなります。
- **掘る** … 光る砂の山にしばらく止まると、埋まった宝物が出ます。小さなゲージが埋まりきるとタンクに入ります。

深海（深度Lv5、基地から275以降）では、ときどきアンコウかイカが荷物を狙います。沈没船には、まれにタコもいます。浅瀬や昆布では出ません。攻撃の直前に赤い輪と光で予告するので、輪から外れれば避けられます。当たるとタンクの一部が飛んでいき、相手が持って逃げます。追いかけてカッターで切ると、奪われた分に少し足して戻ってきます。潜水艦が沈むことはありません。一度に奪うのは深海サンゴおよそ2株ぶん（最大8スロット、またはタンクの約3割）までなので、避けそこねても奥へ行く価値は残ります。奪われる量の軽減はデコイです。調整は `src/game/economy.js` のデコイと `src/game/threats.js` の `THREAT` です。

### 操作

- キーボード: `WASD` または矢印キー
- マウス / タッチ: 画面をドラッグ（押し始めた位置がスティックの中心）
- 見える範囲: マウスホイール、または2本指のピンチ。選んだ倍率はセーブされます
- 音: 「音ON / 音OFF」で全部ミュート。隣の♪から BGM と効果音の音量（0〜100%）を別々に変えられます。どちらもセーブに残ります

進行状況（所持金、強化、深度、デコイ、拠点レベル、設備、前線基地、音量、累計）はブラウザの `localStorage`（キー `coral-cutter-save-v1`）に保存されます。古いセーブ（version 1 と 2）は消しません。カッターは以前の威力に合わせて新しいレベルへ読み替え、タンク・速度・売値は以前の数値を下回らない段階へ、深度はそのカッターで入れていた海域に合わせます。タンクの中身、位置、飛行中のドローンは保存しません。合わないときはタイトル画面の「データ消去」で最初からやり直せます。

## 音

BGM と効果音は、音源ファイルを同梱せず、ブラウザの Web Audio でプレイ中に合成しています。外部の楽曲やサンプルは使っていません。このリポジトリで書いたオリジナルの手続き合成です（著作権のある音楽はありません）。

BGM はゆったりしたペンタトニックのループです。海域が深くなるほど音程が下がり、フィルターがこもって、低いドローンが少し強くなります。浅瀬と基地は明るく、昆布・サンゴと沈没船を経て、深海がいちばん低く暗いです。BGM は効果音より小さめに混ざっています。スマホでも聞こえるよう全体は大きめで、マスターには軽いリミッターを入れています。

効果音は短く、高い帯域を抑えています。連打で音が割れないよう、同時に鳴る数を制限しています。

| 呼び出し | 場面 |
| --- | --- |
| `playSfx('cut')` | 切断。速く刈っても同じ音が続かないよう、ピッチが少しずつ変わります |
| `playSfx('pickup')` / `playSfx('vacuum')` | 刈った荷物をタンクへ吸い込むとき |
| `playSfx('full')` | タンクが満タン |
| `playSfx('sell')` | 基地での売却（コインが連なる音） |
| `playSfx('buy')` | 強化の購入 |
| `playSfx('deny')` | お金が足りず強化できないとき（やわらかい音） |
| `playSfx('zone')` | 別の海域に入ったとき。深く入ると下降、戻ると上昇 |
| `playSfx('ui')` | ボタンを押したとき |
| `playSfx('clank')` | まだ切れない相手に当たったとき |
| `playSfx('shatter')` | 大きめの通常の資源が割れたとき |
| `playSfx('bigHit')` | でかい獲物へのヒット（重い打撃） |
| `playSfx('bigBreak')` | でかい獲物が割れたとき |
| `playSfx('catch')` | 魚を網に入れたときの水音 |
| `playSfx('bonk')` | 閉じた大貝に当たったとき |
| `playSfx('pearl')` | 開いた大貝から真珠を取り出したとき |
| `playSfx('tow')` | 重い荷物にケーブルを繋いだとき |
| `playSfx('dig')` | 砂を掘って宝物が出たとき |
| `playSfx('warn')` | 深海の泥棒が攻撃を予告したとき |
| `playSfx('steal')` | タンクの荷物を奪われたとき |

最初のタップ、またはキー入力まで音は鳴らしません（スマホの自動再生制限のため）。タブを隠すと BGM も効果音も止まり、戻すと再開します。Android Chrome と iOS Safari では、操作の中で `AudioContext` を作り `resume()` しています。

## 開発・実行

```bash
npm install
npm run dev
```

開発サーバーは <http://localhost:5173/> です。

```bash
npm run build
npm run preview
```

`npm run build` のベースパスは GitHub Pages のプロジェクトサイト向けに `/CoralCutter/` です。プレビューする場合は <http://localhost:4173/CoralCutter/> を開いてください。

## GitHub Pages

`.github/workflows/pages.yml` が、デフォルトブランチ（`main`）への push でビルドし、GitHub Pages へデプロイします。pull request ではビルドだけ走ります。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。未設定のままだと、マージ後のデプロイジョブが失敗します。

公開URLの例: `https://qnaiv.github.io/CoralCutter/`

## これからの拡張

吸い込み、ドローン、ワープ、前線基地はすでに遊べます。刈り取りは `Resources.harvestAround` にまとめてあります。まだ入れていないのは相棒の小型潜水艦と、任意のリワード広告です。プロトタイプには広告を入れていません。
